Added an interactive Mac owner-psql helper to avoid copying owner credentials into command arguments. It validates the explicit development target, uses installed Postgres.app, skips startup files and supplies a mode600 password file inside a mode700 temporary directory. Password entry remains in the user's private terminal; the helper runs no setup SQL itself.
