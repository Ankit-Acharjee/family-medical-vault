# SHARE-02 — Temporary sharing delivery

Owner-only creation, explicit original selection and 1–168 hour expiry, bearer-access confirmation, one-time fragment secret, uncertain-create retry identity, bounded history, revocation and recent anonymous access activity are implemented. Recipient access is isolated from account/vault loading and requires the secret for each POST; no obligatory recipient signup. Secrets are removed from the address bar immediately and never persisted in browser storage or database plaintext. Reload requires reopening the original secret link.

Original reads use the existing bounded object adapter, validate MIME/length/hash, and recheck locked source/owner/lifecycle/expiry/revocation after fetching and audit. Anonymous activity is separate from owner document events. No public storage URL, implicit whole-vault selection, derived record or owner impersonation. Access events are not unique-visitor counts or proof of saving to disk. Downloaded copies cannot be recalled.
